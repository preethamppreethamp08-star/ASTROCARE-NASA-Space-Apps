# Dataset Storage Directory

Place raw datasets locally here when running offline Python scripts or tests:
- `MMASH.zip` (Multilevel Monitoring of Activity and Sleep in Healthy people)
- `LSDS-7_Complete_Blood_Count_CBC_TRANSFORMED.csv`
- `LSDS-8_Multiplex_serum.immune.EvePanel_SUBMITTED.csv`

Datasets from separate studies are never merged across cohorts.
